# ⏰ Delayed Message App

A simple, responsive web application built using HTML, CSS, and JavaScript that displays a user's message after a selected time delay.

### 🌐 Live Demo

[Try the Delayed Message App](https://chaudharyvani0-beep.github.io/Delayed-Message-App/)

### ✨ Features

- Enter a custom message.
- Choose a delay of 1, 2, or 3 seconds.
- Display a "Waiting..." message during the delay.
- Validate empty input fields.
- Cancel previous pending timers to display only the latest submitted message.
- Clean, responsive design with a pink theme.

### 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — DOM manipulation, event handling, and timer functionality

### 🧠 JavaScript Concepts Practiced

- `querySelector()`
- `addEventListener()`
- `setTimeout()`
- `clearTimeout()`
- `.value` and `.trim()`
- Input validation

### 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

### 📌 Project Purpose

This project was created to practice asynchronous JavaScript concepts and understand how timers work with user interactions.
